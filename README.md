# Deep-Learning-Implementation-and-Visualization

This project is made to help anyone in his learning journey of Deep learning and Machine learning. It does not explain everything, but it helps in having a good intuition about how weights change over the iterations and how does it manage to make the final decision. I only calculated the precision for now which is only one metric out of many, you should be able to draw your custom number to test the model at different iterations or epochs. 

This project may not be perfect. I published the project with the intention that I will be continously updating it based on what I can learn from my learning journey and based on your feedback, so dont hesitate to let me know if there is any misspelling, code optimization or problems that you come across as well as suggestions for new features of course.
